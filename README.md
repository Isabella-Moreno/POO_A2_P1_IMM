## Funcionalidades
- **Ejercicio 1 (`Ejercicio1`):** Implementación de herencia entre `Persona` y `Empleado`, sobrescribiendo `mostrarDetalles()` con `super` para reutilizar la lógica base y añadir el departamento (`EmpleadoPrueba`).
- **Ejercicio 2 (`Ejercicio2`):** Implementación de `Animal` y `Pez`, utilizando `super` tanto para invocar el constructor de la clase padre como para extender el método `mostrarEspecie()` (`PezPrueba`).
- **Ejercicio 3 (`Ejercicio3`):** Demostración y análisis de errores de compilación al emplear `super` fuera de una relación de herencia (`UsoIncorrectoSuperPrueba`) y al intentar acceder a atributos `private` de la clase base (`Planta` y `Orquidea`).
